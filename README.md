# Meu Grupo

App web (PWA) para superintendentes de grupo: importar `GrupoN.t09`, lançar relatórios e exportar `GrupoN.t19`.
Funciona sem internet e não envia dados para nenhum servidor: tudo fica no navegador.

## Publicar
1. Cloudflare Pages ou Netlify → importar este repositório.
2. Sem comando de compilação; pasta de saída: raiz (`/`).
3. Abrir o link por HTTPS e usar "Adicionar ao ecrã principal" para instalar no telemóvel.

Sem hospedagem, o `index.html` também funciona aberto diretamente.
